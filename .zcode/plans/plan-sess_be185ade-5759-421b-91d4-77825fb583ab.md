## 摸鱼彩蛋实现方案

### 目标
点击鱼时,以 0.4 概率触发"摸鱼"彩蛋:鱼停止游动,一只手从上方伸下来抚摸鱼的背部。与现有「刷牙」彩蛋(0.4)互斥,避免视觉冲突。

### 改动点(共 3 处,全部在 `index.html`)

#### 1. CSS — 新增摸鱼彩蛋样式(插入到第 61 行 `brushBubble` keyframe 之后)
仿照刷牙彩蛋的样式风格,新增:
- `.fish-wrapper.petting .fish-float svg` — 抚摸期间鱼轻微呼吸缩放(`petBreath` 动画)
- `.fish-pet-hand` — 手的 SVG 容器,`position:absolute`,从鱼背上方下探
- `@keyframes petStroke` — 手"下落 → 左右轻抚 → 抬起 → 循环"(约 1.25s 一轮,3.2s 内循环约 2.5 次)
- `.pet-sparkle` — 抚摸时飘出的爪印 / 爱心 / 星星(复用 `brushSparkle` 的销毁逻辑思路,独立 keyframe `petSpark`)
- `@keyframes petSpark`

手挂在 `mainFishSvg` 内部(随 `fishWrapper` 的 `scaleX(fishDir)` 一起翻转,方向自动跟随鱼),不旋转鱼身(区别于刷牙的竖立)。

#### 2. JS — 新增 `triggerFishPet()` 与 `playPetSound()`(插入到第 1705 行 `triggerFishBrush` 结束之后,音效插入到第 1641 行 `playBrushSound` 之后)
**`triggerFishPet()`**,逻辑完全对称于 `triggerFishBrush()`:
- `fishPetting = true` 守卫;`fishPaused = true; fishVX = 0; fishVY = 0;` 停止游动
- `fishWrapper.classList.add('petting')`
- 在 `mainFishSvg` 内 `appendChild` 一只 SVG 卡通手(掌心朝下,位于鱼背 cx≈130、上方 y≈-30 → 下探到 y≈35),由 `petStroke` 驱动抚摸
- 每 ~220ms 随机生成一个 `🐾 / 💕 / ✨ / 🫧` 粒子(飘在鱼背附近,`animationend` 自移除)
- `fishSay('别摸啦～好痒！🐟💕')`(2 秒气泡,与刷牙同套文案机制)
- `playPetSound(3.0)` —— Web Audio 合成轻柔"咕噜"声:低频(~100Hz)正弦 + 极轻白噪声 + 慢速颤音 LFO,音量 0.10(比刷牙 0.18 更轻柔)
- `DURATION = 3200` 后清理:移除 `.petting` 类、移除手元素与所有粒子、`fishPaused = false; fishPetting = false`(与刷牙的恢复时序一致)

**手 SVG 设计**:简笔卡通手掌(肤色渐变 + 指节),`viewBox="0 0 80 90"`,挂在鱼 SVG 内坐标约 `(110,-20)` 处,`transform-origin: top center`,由 `petStroke` 控制下探与左右轻抚幅度 ±18px。

#### 3. JS — 改写点击处理器的彩蛋触发(第 1749-1752 行)
把现有的单一刷牙判断:
```js
if (Math.random() < 0.4) { setTimeout(triggerFishBrush, 420); }
```
改为**互斥三段** + **进行中守护**:
```js
if (!fishBrushing && !fishPetting) {
  const r = Math.random();
  if (r < 0.4)        setTimeout(triggerFishPet, 420);   // 摸鱼 40%
  else if (r < 0.8)   setTimeout(triggerFishBrush, 420);  // 刷牙 40%
  // r >= 0.8:无彩蛋 20%
}
```
精确满足"摸鱼 0.4";刷牙总概率保持 0.4 不变;彩蛋进行中再次点击不会叠加触发。

### 验证方式
实现后在浏览器中多点几次鱼,确认:
- 约 40% 出现手抚摸(鱼停下、手下探左右轻抚、有粒子和气泡文字、3.2s 后恢复游动)
- 约 40% 仍是刷牙(行为不变)
- 抚摸期间再点鱼不会触发新彩蛋或重叠
- 手机端(窗口 ≤480px)手的位置与鱼身对齐正确
